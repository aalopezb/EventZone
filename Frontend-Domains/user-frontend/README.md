# Frontend Domain

This domain contains the central frontend application of EventZone, built with React.

It provides the user interface that connects and interacts with all backend microservices, allowing users to browse events, manage profiles, make reservations, and more.

---

## Key Features

- Integrates with multiple microservices through REST, GraphQL, and gRPC APIs.
- Centralized navigation and routing for all platform functionalities.
- Responsive design for desktop and mobile devices.
- Handles authentication and authorization flows with JWT tokens.
- Real-time updates and notifications integration.
